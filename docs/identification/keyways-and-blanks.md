# Commercial & Residential Keyway Identification

Keyway warding determines which pick profiles, decoders, and blanks can access the internal cylinder plug. Recognizing keyway profiles in the field allows operators to immediately determine pin clearance, identify master-keyed multiplex architectures, and select appropriate key blanks.

---

## Keyway Taxonomy & Geometry

Lock cylinders use specific warding profiles designed to prevent unauthorized key entry and restrict pick manipulation:

```text
Open Keyways (e.g. KW1, M1)
  - Straight, wide open keyway channel
  - Accepts standard 0.025" picks and wide tensioners

Paracentric Keyways (e.g. SC1, Y1, Sargent LA)
  - Curved warding extending past the vertical centerline
  - Requires navigating around shelves; best suited for 0.020" or 0.015" picks

Multiplex Keyways (e.g. Schlage Obverse/Reverse, Corbin Russwin System 70)
  - Hierarchical family tree of milled profiles
  - Sub-master and grand-master keys bypass multiple individual cylinder profiles

Restricted / Patented Profiles (e.g. Medeco, Schlage Primus, Assa Twin)
  - Secondary locking sidebars, angled cuts, or factory-controlled distributions
```

## Schlage Classic Multiplex System

Schlage's classic commercial architecture utilizes a sophisticated multiplex keyway structure. In a multiplex system, individual sub-level keyways are milled with specific warding projections, while higher-level master keys have thinner profiles that bypass multiple individual cylinder keyways.

### Obverse Key Hierarchy

The primary commercial series is the **Obverse** family:

| Tier | Profile Designations | Function & Access Scope |
| :--- | :--- | :--- |
| **All-Section Master** | **H** | Enters all Obverse cylinders (C, CE, E, EF, F, FG, G) |
| **Multi-Section Sub-Master** | **C-E** | Enters cylinders keyed with C, CE, and E keyways |
| **Multi-Section Sub-Master** | **E-G** | Enters cylinders keyed with E, EF, F, FG, and G keyways |
| **Multi-Section Sub-Master** | **C-G** | Enters all standard single-section cylinders |
| **Single-Section Change Keys**| **C, CE, E, EF, F, FG, G** | Individual operating keys; enter only their matching cylinder plug |
| **Universal Plug** | **U Keyway** | A broached cylinder plug designed to accept all Obverse keys (C through H) |

```text
                  [ H ] (All-Section Master Key)
                 /     \
         [ C-E ]         [ E-G ] (Multi-Section Sub-Masters)
        /   |   \       /   |   \
     [ C ] [ CE ] [ E ] [ EF ] [ F ] [ FG ] [ G ] (Single-Section Keys)
        \   \     \   /   /     /     /
         \---\-----\-/---/-----/-----/
                      |
              [ U Keyway Plug ] (Accepts All Obverse Keys)
```

### Reverse Key Hierarchy

Schlage also manufactures a mirrored **Reverse** keyway family to prevent crossover between separate facilities or departments within large institutions:

| Tier | Reverse Profile | Obverse Counterpart | Scope |
| :--- | :--- | :--- | :--- |
| **All-Section Master** | **L** | **H** | Enters all Reverse cylinders (D, DQ, Q, QS, S, ST, T) |
| **Multi-Section Sub-Master** | **D-Q** | **C-E** | Enters D, DQ, and Q keyways |
| **Multi-Section Sub-Master** | **Q-T** | **E-G** | Enters Q, QS, S, ST, and T keyways |
| **Single-Section Change Keys**| **D, DQ, Q, QS, S, ST, T** | **C, CE, E, EF, F, FG, G** | Individual operating keys |
| **Universal Plug** | **Z Keyway** | **U Keyway** | Accepts all Reverse keys (D through L) |

## American Lock Keyway Taxonomy

American Lock padlocks and commercial utility cylinders use an interlocking set of model numbers, blank references, and factory designations that frequently cause confusion in the field:

| Common Designation | Manufacturer / Blank Name | Pin Count | Cross-References | Profile Characteristics |
| :--- | :--- | :--- | :--- | :--- |
| **AM3** | American Lock AK5 | 5-Pin | Ilco 1045, JET AM6 | Standard commercial profile (PTKB1 base profile) |
| **AM4** | American Lock AM4 | 5-Pin | JET AM6L | Long neck version of AM3; clears protective shackle shrouds |
| **AM5** | Original Lishi Tool | — | — | **Not a key blank**; tool model designation for decoding 5-pin American locks |
| **AM6** | Curtis / Hillman / JET | 5-Pin | Ilco 1045 | Legacy distributor designation for AM3 |
| **AM7** | American Lock AK6 | 6-Pin | Ilco A1045, JET AM7 | Standard 6-pin version of the PTKB1 profile |
| **PTKB1** | American Lock Factory Profile | 5/6-Pin | AK5 / AK6 | Base standard profile across commercial padlocks |
| **PTKB2** | Narrow Blank Profile | 5/6-Pin | — | Narrowed warding profile for tighter security housings |
| **PTKB748** | Restricted Blank | 5/6-Pin | — | Factory-restricted profile for proprietary commercial installations |
| **R7** | Reverse Restricted | 5/6-Pin | — | Direct mirror reverse of the PTKB748 profile |

| Equipment / System | Key Code / Marking | Blank Reference | Common Applications |

## Ilco Key Blank Directory Cross-Referencing

When identifying unknown blanks in the field, use the industry standard cross-reference indices published in the Ilco Key Blank Directory:

- **North American Cylinders (Part 04):** Indexes commercial architectural cylinders (Schlage, Sargent, Yale, Corbin Russwin, Falcon, Dexter, Weiser, Weslock, Arrow).
- **Vehicular Key Directory (Part 03):** Indexes automotive, truck, and commercial vehicle ignitions and door locks.
- **Cross-Reference Table (Part 12):** Provides direct translation across competing aftermarket manufacturers:
  - **Ilco** (e.g., 1045 / A1045)
  - **Curtis** (e.g., AM3 / AM7)
  - **Dominion**
  - **ESP**
  - **Jet** (e.g., AM6 / AM7)
  - **Star**
  - **Taylor**
