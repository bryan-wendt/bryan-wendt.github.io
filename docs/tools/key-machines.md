# Key Cutting & Code Origination Machines

In physical security assessments, locksmithing, and covert operations, operators frequently need to originate factory-specification keys directly from decoded bitting numbers rather than tracing a worn existing key on a standard duplicator. Code machines cut blank keys according to exact mathematical depth and space coordinates.

---

## Duplicators vs. Code Machines

- **Key Duplicators:** Trace the profile of an existing key with a mechanical guide finger while a rotary cutter cuts a matching blank. If the source key is worn, damaged, or poorly duplicated, the duplicator copies those exact defects.
- **Code Machines:** Cut directly from numerical bitting data (e.g., `4-7-2-1-8`) without requiring an original key. This produces a factory-new key with crisp root flats and exact angles that eliminate generation wear.

---

## The HPC 1200CMB "Blitz" Machine

The HPC 1200CMB (commonly known as the **Blitz Machine**) is the industry standard mechanical code machine for commercial locksmiths and field security teams.

```text
       [ Code Card Slot ]
               |
               v
      [ Depth Crank Dial ] <---- Adjusts vertical cutter height
               |
      [ Spacing Crank ] <------- Advances carriage horizontally
               |
       [ Clamp Vise Jaw ] <----- Secures blank key (Shoulder or Tip Stop)
               |
       [ Rotary Cutter ] <------ Carbide or high-speed steel milling wheel
```

### Core Mechanical Components

1. **Code Cards:** Precision metal or high-density plastic cards inserted into the machine carriage. Each card corresponds to a specific manufacturer (e.g., Card C39 for Schlage Classic, Card C1 for Kwikset):
   - **Horizontal Index Lines:** Indicate the center-to-center cut spacing (BCC) from first cut (TFC) to the tip.
   - **Vertical Increment Scales:** Indicate the factory bitting depths (0 to 9).
2. **Depth Crank (Micrometer):** Elevates or lowers the key vise carriage toward the spinning cutter wheel to regulate root depth.
3. **Spacing Crank:** Advances the carriage left-to-right along the blade length, aligning the pointer with the card's position marks.
4. **Horseshoe Vise Jaw:** Hardened steel clamp holding the key blank rigidly. Features two reference stops:
   - **Shoulder Stop:** Flip-down gauge aligning keys that index from the bow shoulder.
   - **Tip Stop:** Gauge gauge aligning keys that index from the blade tip (e.g., BEST SFIC).
5. **Cutter Wheels:**
   - **CW-1011 (100° angle, .045" flat):** Standard milling cutter for commercial cylinders (Schlage, Yale, Kwikset).
   - **CW-14MC (90° angle, .030" flat):** Small-diameter milling cutter for Master Lock, American Lock, and narrow padlocks.
   - **CW-90MC:** Dedicated 90° cutter for Small Format Interchangeable Cores (BEST).

## Calibration & Zero-Point Alignment

Accurate key origination requires verifying the Blitz machine's zero points before cutting:

### 1. Depth Calibration
1. Insert the blank calibration gauge or standard factory key into the vise.
2. Dial the micrometer depth dial to zero (`.000"`).
3. Raise the carriage until the calibration disc touches the perimeter of the cutter wheel without binding.
4. Adjust the depth adjustment screw on the rear bracket until the dial matches the test gauge measurement.

### 2. Spacing Alignment
1. Align the carriage pointer with the index mark of the first cut position on the code card.
2. Lower the alignment finger into the vise jaw datum line.
3. Ensure the spacing crank indicator sits dead center on the spacing line to prevent cuts from wandering toward the tip or shoulder.

## The HPC 1200PCH "Punch" Machine

While the rotary Blitz machine mills keys using a spinning cutting wheel, the **HPC 1200PCH Punch Machine** cuts keys using a heavy mechanical punch and die:

### Operational Advantages of Punch Machines
- **Zero Brass Shavings:** The punch cleanly shears a crescent or V-shaped brass slug from the blade into an internal collection tray, producing zero airborne metal shavings. This makes it ideal for cleanroom facilities, data centers, and field response vans.
- **Factory Edge Finish:** Leaves smooth, burr-free root flats that require minimal wire brush deburring.
- **Speed:** Operators can punch a standard 6-pin key in under 15 seconds by rapidly advancing the index crank and depressing the mechanical punch arm.
