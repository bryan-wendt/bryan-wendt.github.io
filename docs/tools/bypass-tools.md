# Specialized Bypass Equipment

Specialized bypass tools are engineered to interact with latches, handles, electronic sensors, or hardware gaps directly to bypass the locking cylinder entirely.

---

## Core Equipment Profiles

| Tool Name | Target Hardware | Mechanism |
| :--- | :--- | :--- |
| **Under-Door Tool (UDT)** | Interior lever handles and crash bars | Flexible wire with lasso cable that slides under door undercut |
| **Shove Knife** | Outswing spring latches (key-in-knob/lever) | Flexible blade notched to catch and retract latch bolt bevel |
| **Traveler Hook** | Adams Rite commercial storefront swing latches | Angled hook inserted through keyway hole or reveal |
| **Padlock Shims** | Spring-loaded padlock locking dogs | Formed curved stainless steel shims inserted down the shackle collar |
| **Comb Picks** | Low-tolerance solid body padlocks | Multi-tine pick that pushes entire pin stacks above the shear line |
