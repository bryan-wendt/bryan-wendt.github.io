# Agent Guidelines & Rules

## Git Workflow & Push Restrictions
- **NEVER PUSH**: Never run `git push` or attempt to push commits/branches to any remote repository. All pushing to remote is strictly performed manually by the user.
- **Local Commits**: You may stage (`git add`) and commit (`git commit`) changes when requested by the user, but never push them.

## UI & Content Design Rules
- **NO EMOJIS**: Never use emojis anywhere in the website UI, documentation, markdown, or code unless explicitly requested by the user. Use clean text or lightweight, professional SVG icons sparingly instead.
